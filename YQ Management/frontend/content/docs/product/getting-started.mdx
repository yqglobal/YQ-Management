# Getting Started

Step by step guide to creating your first workspace and locations.

<Callout type="warning" title="Prerequisites">
  Make sure you have an active Qmova subscription before proceeding.
</Callout>

## Creating a Location

1. Go to your dashboard.
2. Click **Locations**.
3. Add a new location.
